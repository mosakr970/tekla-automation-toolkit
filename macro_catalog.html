Installing a macro

The same three steps for all five
  1. Copy the .cs file into the first folder listed in the XS_MACRO_DIRECTORY advanced option. Model macros go in modeling\ and drawing macros in drawings\.
  2. Restart Tekla. It only registers macros at startup.
  3. Open Applications & components → Macros and run it. Run drawing macros with the drawing open.

Updating a macro? Restart Tekla after you replace the file. Tekla loads each macro once per session, so until you restart it keeps running the old version.

The macros

What each one needs from you, what it saves and where it stops
MOD-01

Insert Tendons

ModelVerified on live project

Models post-tensioning tendons and their ducts in precast beams straight from the designer's Excel profile. It handles beams that slope or are rotated, and polybeams.

You provide
  • One Excel sheet per beam position, giving the station, the offset across the width and the height above the soffit for each tendon point
  • Tendon and duct profile and material, picked from the catalog
How it works
  • Beams tab: Scan groups the beams by EK_MARK, or by assembly position when that is empty. Then assign a file to each position.
  • Results tab: one row per beam, showing inserted, skipped or failed. Double-click a row to zoom to the beam.
  • Beams that already hold tendons with that name are skipped, so running it again is safe.
Live project run
~5 minwhole session, including setup
~40 hteam estimate by hand

Watch out for
  • The beam must be modelled from start to end (PA to PG). If it runs the other way, the profile comes out mirrored.
  • The tendon runs straight between sheet rows. Where the soffit changes slope, add a row at that station.
  • It doesn't follow polybeams that bend in plan, only bends in elevation.
MOD-02

EK Mark

ModelNew window not yet run in Tekla

Compares assemblies and cast units part by part and numbers the EK_MARK UDA, so identical pieces share a mark (TT-001) and each different piece gets the next number.

You provide
  • A prefix and start number on each assembly or cast unit, for example 001, 100 or 200 per floor
What counts as different
  • Name, profile, material and finish of every part, including sub-assemblies
  • Solid geometry: length, cuts, fittings and chamfers
  • Bolt holes, welds, surface treatments, and rebar the way Tekla numbers it
  • A copy turned 90° or 180° still matches. A mirrored copy doesn't.
How it works
  • Scan, select the group rows, then click Number. Existing marks are kept, and a piece that no longer matches its mark is reported rather than changed.
  • Tick Overwrite to clear the marks and renumber from scratch.
  • A piece whose number would run into the next floor's range gets no mark and is shown in red.

MOD-03

HC Check

ModelEnter a real factory catalog first

Measures every hollow-core panel and reports the ones the factory can't make. That covers widths where the saw would cut through a web, and openings outside the limits for their zone (near a support, at mid-span, at the edge).

You provide
  • The factory's width bands and opening limits for each panel profile, entered in the macro's window. It takes about an hour per catalog and is reused by every model on that catalog.
  • An example ranges file ships with it: hc_check.sample.json
How it works
  • Failing panels turn red in the model and are listed in a sortable table. Double-click a row to zoom to the panel.
  • It measures the real width across the cut solid, so panels narrowed by a cut are caught.
  • Top-surface recesses such as tie-bar slots are counted and skipped, not flagged as openings.

Why it matters

By hand, 851 panels is 7 to 28 hours, so in practice nobody checks every one. With the macro, every panel gets checked on every revision, and a width no saw can cut is caught in the model rather than at the factory.

DRW-01

Opening Marks

DrawingDimensions not yet checked

Finds every opening and recess in a floor plan view and crosses it out: two diagonals for an opening, one for a recess. It also finds holes no cut makes, like a stair hole left between planks.

You provide
  • A floor plan view selected in the open drawing
  • Optional limits: Min opening (50 mm), Joint gap (150 mm), Recess (200 mm), line colour and type
How it works
  • Scan lists the openings under five types: inside element, edge/corner, outer edge notch, between elements, recess.
  • Tick MARK for the crossing and DIMS for the size. Selecting a row outlines that opening in magenta.
  • Mark never duplicates a line it already drew. Remove deletes only the macro's own marks, by type.

DRW-02

Auto Dimension

Drawing3 new options not yet run in Tekla

Dimensions the assemblies in a drawing view to the nearest grid line. Elements in a row get one chain showing each length and the gaps, and openings are included in their element's chain.

You provide
  • A selected drawing view
  • The numbering series to dimension. Leave rebar and embeds unticked.
  • Openings on or off per series. Walls and slabs want them, beams and columns usually don't.
How it works
  • Scan, tick series, then add dimensions. The window stays open, so you can work one series at a time and check the drawing in between.
  • Dimension lines sit on a real face, close to the part, and move aside for existing marks, text and dimensions.
  • After a model change, delete the dimensions and run it again.
What it saves

A row of eight panels by hand means eight overall dimensions and seven joints, each one picked and nudged. The macro draws one chain. You still review the drawing, but placing the dimensions is no longer manual, and every view follows the same rules whoever is on the job.

Status: in use on drawings. The Grids, Every part and contour-plate length options compile but haven't been run inside Tekla yet. It hasn't been timed against doing it by hand.
Watch out for
  • Chamfered or stepped ends are measured to the bounding box, not the drawn edge.
  • Offsets are in model mm, so the gap on paper changes with the view scale.
  • A 5 mm joint at 1:60 is correct but too small to read.
