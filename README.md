# Tekla Automation Toolkit

Three single-file Tekla Structures macros for precast work, with a case study for each.

| Tool | Case study |
|---|---|
| HC Check: hollow-core panel manufacturability checker | `hc-check.html` |
| Auto Dimension: dimensions a drawing view the way a detailer would | `auto-dimension.html` |
| Insert Tendons: models post-tensioning from the designer's Excel profile | `insert-tendons.html` |

Live site: https://mosakr970.github.io/tekla-automation-toolkit/

Author: Mohamed Sakr, Structural Engineer, BIM & Digital Delivery, Tallinn, Estonia.
