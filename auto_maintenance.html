Tick the housekeeping steps you want, press Run, and the plugin does them in order from one window: save, Organizer sync, diagnose and repair, backup, baseline, and a zipped copy of the latest backup sent to the server. A progress log shows each step, and a failed step stops the run and says why.

A

What it does

It is a model plugin with a window. The end-of-day routine that is a dozen manual clicks and several long waits becomes one list of steps the plugin walks through, driving Tekla's own commands and dialogs for you and waiting for each to finish before the next.

  1. 01

    Save model

    Commits the model, so everything after it runs on saved data.

  2. 02

    Organizer sync

    Opens Organizer, presses Synchronize, waits for the sync to finish (up to the minutes you set), closes Organizer and saves again. If nothing needs syncing it skips the wait.

  3. 03

    Model diagnosis

    Runs Tekla's model diagnose and reports the result.

  4. 04

    Model repair

    Runs Tekla's model repair and reports the result.

  5. 05

    Create backup copy

    Runs Tekla's own backup command, which writes a fresh backup folder of the model.

  6. 06

    Save baseline

    For shared models: opens the Model Sharing dialog, names the baseline with today's date (YYYYMMDD), presses Save, and waits until Tekla's status bar confirms the baseline was written out.

  7. 07

    Archive backup to zip

    Zips the newest backup folder into ModelName_YYYY-MM-DD.zip and copies it to the server folder you set, with a Windows copy dialog so you can see the progress.

B

The window

Each step is a checkbox, so you choose which to run this time. Two folders and a wait time are set on the window and remembered for next time.

Settings on the window
SettingWhat it is for
Step checkboxesTick the steps to run. Unticked steps are skipped. They always run in the order above.
Backup sourceThe folder Tekla writes its backups into. The archive step zips the newest subfolder here.
Archive folderThe server folder the finished zip is copied to.
Organizer sync waitHow many minutes to wait for Organizer sync before giving up and reporting it.
While it runs

The plugin drives Tekla's menus and dialogs through Windows itself, so leave the keyboard and mouse alone while a run is going - clicking into another window can interrupt a step. The log reports each step as it starts and finishes, and Cancel stops after the current step.

C

Limitations

  • It waits on Tekla, and Tekla can be slow workflow

    Sync, baseline write-out and the zip copy can each take many minutes on a large model. Each has a generous timeout and the run stops with a clear message if one is exceeded.

  • Baseline is for shared models scope

    The baseline step uses the Model Sharing dialog. On a model that is not shared, leave that step unticked.

  • Archive needs both folders set workflow

    The archive step stops with a message if the backup source or the archive folder is not set or does not exist.

D

One build for every version

A plugin is a compiled DLL, not source that Tekla compiles at startup, so it has to be built. It is compiled once against the Tekla 2023 assemblies, the oldest version supported, and later versions load it through their own. It is packaged into AutoMaintenance_1.2.tsep, which installs it into every Tekla version from 2023 on.

E

Running it

  1. Install the plugin: double-click AutoMaintenance_1.2.tsep, or open it in Tekla's Extension Manager. It installs into every Tekla version from 2023 on. Then restart Tekla.
  2. Open the model and start Auto Maintenance from Applications & components.
  3. Set the backup source and the archive folder once, and the Organizer sync wait if the default does not suit.
  4. Tick the steps you want for this run. Untick baseline on a model that is not shared.
  5. Press Run, then leave Tekla alone. Watch the log until it finishes, or press Cancel to stop after the current step.
