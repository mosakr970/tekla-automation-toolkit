Pick a point, pick where the text goes. The plugin writes the point's coordinates beside it with a leader line, measured from the base point the view is located by, in the order, unit and decimals set in its dialog.

A

What it does

It is a drawing plugin, not a macro. Each mark it places stays a plugin object in the drawing, with its two picks as handles, so its settings can be changed later and Tekla runs it again when the drawing is opened.

  1. 01

    Set the format

    In the dialog: which of X, Y and Z to show, each with a prefix and a postfix, the order of the lines, the unit, the decimals and the text attribute file. Settings can be saved under a name and loaded again.

  2. 02

    Pick the point, then the text location

    Both picks are taken together, so they always lie in the same view. The plugin places a text at the second pick with a leader line to the first, one line per coordinate.

  3. 03

    Change marks already placed

    Modify writes the dialog's settings to the selected marks and rewrites their text. Get reads the settings of the selected mark back into the dialog.

B

Which coordinate system

A drawing view already says where its coordinates are measured from, in its Location by property. The plugin reads that property and uses it, so the mark always agrees with the view it sits in. There is no separate setting to keep in step.

The work plane

The picked point comes in the view's display coordinates. It is turned into global model coordinates with the view's coordinate system, then into the base point's coordinates with BasePoint.ConvertToBasePoint. That call reads its input in the current work plane, not in global coordinates, so the plugin sets the global work plane for the call and restores the previous one in a finally.

OK and Apply set the values for new marks · Modify writes them to the selected marks · Get reads them from the selected mark · Load and Save work on named settings in the model's attributes folder.

D

The dialog's traps

Each of these makes the plugin do the wrong thing without an error.

  • An Integer 0 arrives as blank. Tekla hands an integer field of 0 to the plugin as blank, which reads as "not set" and falls back to the default of 3 decimals. Decimals is passed as text instead.
  • A cleared checkbox is blank too, not 0. Only a 1 means ticked.
  • Inputs are found by reflection. Tekla binds the dialog's inputs by reading the form's private instance fields, the way the designer would generate them. An input held only in a local variable is never bound.
  • A binding writes only when its input is validated. A checkbox or a list can skip that before a button is pressed, so the button used the old value. Every change is now written at once.
  • A first run has nothing saved. With no standard values yet, every field is blank, which would create marks with no coordinates. The defaults are written through Tekla's own storage when the dialog opens, because setting the inputs directly is undone when the storage refreshes them.

And one in the formatting: a small negative value rounded to zero printed as -0.000. Adding 0.0 after rounding turns the negative zero into a plain zero.

E

One build for every version

A plugin is a compiled DLL, not source that Tekla compiles at startup, so it has to be built. It is compiled once against the Tekla 2023 assemblies, the oldest version supported, and later versions load it through their own. Build-Tsep.ps1 compiles it and packages it into config/release/EKCoordinateMark_1.1.tsep, which installs it into extensions\EKCoordinateMark of every Tekla version from 2023 on.

F

Limitations

  • A pick outside a view creates nothing workflow

    A point picked on the sheet outside any view has no model position. The plugin creates nothing, without a message.

  • One point per mark workflow

    Marking many points means picking each one.

H

Running it

  1. Install the plugin: double-click EKCoordinateMark_1.1.tsep from config/release/, or open it in Tekla's Extension Manager. It installs into every Tekla version from 2023 on. Then restart Tekla.
  2. Open a drawing, and check the view's Location by is the base point the coordinates should be measured from.
  3. Start EKCoordinateMark from Applications & components. Set the coordinates, order, unit and decimals, and Save them under a name to use again.
  4. Pick the coordinate point, then pick where the text goes, in the same view.
  5. To change marks already placed, select them, change the settings and press Modify.
