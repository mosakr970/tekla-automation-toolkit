Macro Guide

Tekla macros and one drawing plugin that take the repetitive measuring, marking and modelling out of our work. This guide covers what each one does, how to set it up, how to use it step by step, what every setting means, and where it stops. Each one has its own .tsep installer. A double-click installs it into every Tekla version from 2023 on. Tekla Setup sets up a newly installed Tekla version itself.

Getting started

The same for all macros and the plugin

1. Get the installers

There is one installer per macro and one for the plugin, kept here:

[MACROS FOLDER PATH] └── release\ InsertTendons_1.1.tsep · EKMark_1.1.tsep · HCCheck_1.1.tsep · OpeningMarks_1.1.tsep · AutoDimension_1.3.tsep · DrawingCreator_1.0.tsep · EKReports_1.0.tsep · EKCoordinateMark_1.1.tsep · AutoMaintenance_1.1.tsep · Install-All.bat · Tekla-Setup.exe

2. Install them

Double-click Install-All.bat to queue every installer in the folder for each Tekla version from 2023 on. Tekla installs them the next time it starts. Or double-click each .tsep, or open it in Tekla's Extension Manager. It installs the macro into every Tekla version from 2023 on, for example both 2023.0 and 2025.0, in the common macro folder:

C:\ProgramData\Trimble\Tekla Structures\<version>\environments\common\macros\

Model macros land in modeling\, drawing macros in drawings\. The HC Check installer also puts the starting ranges, hc_check.json, in the macro folder itself. EK Reports does the same with its prefix table, ek_reports.json. Reinstalling replaces these files, so keep a copy of ranges or prefixes you have saved. The plugin installs into extensions\EKCoordinateMark beside the macro folder. If your firm points the XS_MACRO_DIRECTORY advanced option (File → Settings → Advanced options) at a different folder, the installed macros are not listed.

3. Restart Tekla and run

Tekla only picks up macros when it starts. After restarting, open Applications & components and find the tools in the Esplan tools group, each with its own icon. The group shows after one more restart following the first install. The macros are also under Macros, and the plugin is found by searching for EKCoordinateMark. Model macros run with the model open. Drawing macros run with the drawing open.

How the windows behave

  • Every macro opens a small window that stays on top but doesn't block Tekla, so you can keep clicking in the model or drawing while it's open.
  • Nothing happens until you press Scan (Scan model in HC Check, Scan view in Auto Dimension). Scanning only reads, it never changes anything. Drawing Creator has no Scan: it lists the model views as it opens, and changes nothing until you press Create drawings.
  • The window stays open after a run, so you can change a setting and run again.
  • The model macros remember most settings for next time. Opening Marks and Auto Dimension start from their defaults each time.
  • Hover over any field for a short explanation.
  • In the model macros' lists, press Enter to select the selected rows' elements in the model. In Opening Marks, Enter outlines the openings in the drawing. Drawing Creator's list has no Enter. Shift or Ctrl picks several rows.

Updating a macro or the plugin? Install the new .tsep and restart Tekla. Tekla keeps the old version loaded until it restarts, so a new file has no effect before that.

The macros

What each needs, how to use it, what the settings mean, and where it stops
MOD-01

Insert Tendons

ModelVerified on a live project

Models post-tensioning tendons and their ducts in beams and slabs straight from the designer's Excel profile. Every beam of a position gets the same tendons, placed in that beam's own frame, so slope, rotation and a changing soffit are all followed automatically.

Use it when the designer has sent tendon profile sheets and the beams are modelled. Without it, every beam length needs its own custom component, and every point is typed in a frame that changes from beam to beam.

You need
  • One Excel sheet per beam position, named like the position (JPT-104.xlsx). Cell A1 holds the position. Each tendon has its own X, Y and Z columns (X1 Y1 Z1, X2 Y2 Z2 and so on) listing the stations along the beam, the offset across the width from the centre and the height of the tendon's underside above the soffit.
  • The beams' positions in EK_MARK, or their assembly position when EK_MARK is empty
  • The tendon and duct profiles and materials
Step by step
  1. Beams tab: check the Prefix (concrete beams are found by assembly prefix, JPT by default). To work on only some beams, select them in the model first. The prefix still applies to the selection, so empty it if the selected beams have another prefix.
  2. Press Scan. Beams are listed one row per position, with the number of beams.
  3. Press From folder and pick the folder with the Excel sheets. Each sheet is matched to its position by file name. You can also use Browse on a single row, or press Delete on a row to clear its file. Untick Use to leave a position out. The Sheet column shows how many tendons each file holds, in red if the file can't be read or its A1 names another position. Check those before inserting.
  4. Tendon & duct tab: set profile, material, name and class for the tendon and for the duct. Leave the duct profile empty for no duct.
  5. Press Insert tendons. The Results tab shows one row per beam: Inserted, Skipped (already holds tendons), No Excel file, Unreadable sheet or Failed, each with the reason. Press Enter to select the selected rows' beams in the model, or double-click a row to zoom to its beam.
Settings
PrefixJPTAssembly prefix the beams are found by. Required for a whole-model scan.
NameTENDON / DUCTPart name. It is also how earlier tendons are recognised: a beam already holding parts with this name is skipped. A different name adds a second set.
Prefix / Start numberempty / 1Part numbering for the tendons and ducts. Leave empty for Tekla's default.
Offset up0Height of the duct relative to the tendon
Create asSub-assemblySub-assembly in the cast unit, or loose parts

Settings, recent profiles and materials, the last folder and each position's file are remembered per model, in InsertTendons.settings in the model folder.

Measured on a live project

Watch out for
  • The beam must be modelled from start to end (PA to PG). If it runs the other way, the profile comes out mirrored.
  • Tendons run straight between the sheet's rows. Where the soffit changes slope between two rows, add a row at that station.
  • A polybeam that bends in plan isn't followed, only bends in elevation.
  • A changed sheet: delete that position's tendons and run it again.
MOD-02

EK Mark

ModelNewest window options not yet run in Tekla

Compares assemblies and cast units part by part and fills in the EK_MARK attribute as prefix plus number (TT-001, TT-002). Identical pieces share a mark, and every different piece gets the next free number.

Use it when pieces need marking per floor or per type. By eye you'd open pieces two at a time and compare them, and a 10 mm shift of one lifting anchor makes a different piece that nothing in the model view shows.

You need
  • The numbering prefix and start number set on each assembly or cast unit, for example start 001, 100 or 200 per floor. The macro groups by these.
  • Tekla's rebar numbering up to date, if rebar is compared
Step by step
  1. Select assemblies in the model to work on only those, or select nothing for the whole model.
  2. Press Scan. The Groups tab lists one row per prefix and start number, with how many pieces already carry a mark. Press Enter to select the selected rows' pieces in the model, so you can look before numbering. Clear the selection in the model before the next Scan, or it covers only those pieces.
  3. Select the rows to number and press Number.
  4. The Results tab shows each piece's old and new mark and what happened: Kept, Same as another mark, New mark, Conflict or No mark. A red "Kept - identical to" row means two marks hold identical pieces, so tick Overwrite to merge them. Clear lists each piece as Cleared. Sort by the new mark to see each set together. Press Enter to select the selected rows' pieces in the model.
What counts as different
  • Every part of the piece, including sub-assemblies: name, profile, material, finish
  • The solid's shape: length, cuts, fittings, chamfers
  • Bolt holes, welds, surface treatments, and rebar the way Tekla numbers it
  • The relative position of every embed and hole. A copy turned 90° or 180° still matches. A mirrored copy doesn't, because left and right hand pieces are different pieces.
Settings
OverwriteoffClears the selected rows' marks and numbers them afresh, after asking. Use it when identical pieces have ended up with two marks. It is always off when the window opens.
UniqueoffCompares nothing and gives every unmarked piece its own number. Tick Overwrite as well to renumber pieces that already have a mark.
OrderXYZDirection numbers run in, by each piece's centre of gravity: XYZ, YXZ, ZXY or ZYX
Digits3Digits in a new number (001), from 1 to 9. Existing marks are kept as written.
Tol1 mmHow far points may differ and still match
Welds / RebaronInclude welds and rebar in the comparison. Rebar off is about three times faster.
Clear-Empties EK_MARK on the selected rows
Measured
3.6-5 min3,421 pieces, welds and rebar compared
66-93 sthe same without rebar
1,356 / 1,357identical pairs matched Tekla's numbering
0different pieces given one mark
Watch out for
  • The window doesn't respond while it compares. That's expected, so let it finish.
  • Existing marks are never changed silently. A piece that no longer matches its mark is reported as a conflict.
  • A piece whose number would run into the next range (TT-100 reaching TT-200) gets no mark and is shown in red.
  • Tekla's object lock doesn't protect EK_MARK, and the macro doesn't check the lock yet. Select only what you mean to number.
  • Clear can't be undone.
  • If rebar numbering is out of date, the macro asks before writing. Cancel, number the model, and run again.
MOD-03

HC Check

ModelEnter the factory's real catalog first

Measures every hollow-core panel and reports the ones the factory can't make. That covers widths where the saw would cut through a web, cuts that go only part way through a rib, and openings larger than allowed for their zone (at a support or mid-span, at the edge or in the middle).

Use it before issuing slab plans and after every revision. By hand a panel takes about 18 seconds, so a whole model is hours and in practice only gets spot-checked. Mistakes then turn up at the factory as a remade panel.

You need
  • The factory catalog's width bands and opening limits for each profile, entered once in the Ranges tab (about an hour per catalog). They're saved in hc_check.json beside the macro and shared by every model.
  • The panels' assembly prefix, LP- by default
Step by step
  1. Press Scan model. Every profile in use is added to the Panel profiles list, new ones with empty ranges, and the status line gives the count for each. You can also type a profile name and press Add profile, or Remove one so it isn't checked.
  2. Pick a profile and fill in Standard full width, then the widths a narrowed panel may have under Cut panel widths (press Add band for each Min and Max row), and the four rows under Cut limits. Leave a cell blank where the catalog sets no limit. Press Save.
  3. Press Run check. Failing panels turn red in the model and are listed on the Results tab with the reason. Press Enter to select and zoom to the selected rows' panels, or double-click a row for one panel.
  4. Read the first line of the Log tab, "N panels measured. Ribs checked on X, not on Y", to confirm the rib check actually ran.
  5. Clear colours removes the red. Write report saves every measured number to hc_check_report.txt in the model folder.

With panels selected, only those are scanned and checked. With nothing selected, the whole model is checked by prefix.

Full depth5 mmHow far short of full thickness a cut may stop and still count as going through
Ignore partial-depth cutsonSet per profile. Skips cuts that don't go through, such as tie-bar slots. They're counted, not judged as openings.
Flag part-cut ribsonReports cuts that leave a sliver of rib standing
Colour failuresonColours failing panels red. This is temporary and never saved in the model.

Measured

Watch out for
  • Only profiles with ranges entered are checked. The status line says how many panels were skipped and why.
  • The pass/fail result is only as good as the catalog entered. Check it against the factory's sheet.
  • Edits to the ranges are only kept after Save. Reload drops unsaved edits, and closing the window asks before losing them.
  • A profile modelled without its cores can't have its ribs checked. The Log names those panels.
MOD-04

Drawing Creator

ModelNo time by hand recorded yet

Lists every model view as a row and makes a GA drawing of each ticked row with one button. Each row sets the drawing name, the three titles, the saved drawing properties and the saved view properties. Each drawing gets one view, cut from the model view's plane, extent and depth and centred on the sheet.

Use it to make the floor plans and wall elevations of a GA set in one go, instead of one drawing at a time through the same dialogs.

You need
  • A saved model view per drawing: the plan of each storey, the view along each axis
  • Saved GA drawing properties (.gd) and drawing view properties (.vi) in the model, project, firm or system folder, or their attributes folder
  • No drawing open. The drawings are made from the model
Step by step
  1. Close any open drawing and start Drawing Creator from the model's Applications & components.
  2. Type in Filter to narrow the list. The tick box in the list's header ticks or unticks every shown row. Hidden rows keep their ticks but are not made, so clear the filter to make every ticked row.
  3. Per row, fill in the name and titles and pick the Drawing properties and View properties. {view} in a name or title is replaced by the model view's name.
  4. Press Create drawings. The Status column shows each drawing's mark in green, or why the row failed in red. The line at the top counts what was made and what failed.
  5. After saving new property files, press Refresh to read the lists again.

The pin beside the close button keeps the window above Tekla. Unpin it to let Tekla come in front. Drag the window by its top row.

A new row starts as
Drawing nameEK-5- / EK-6-EK-5- for a view with 'plaan' in its name, EK-6- for 'teljel'. Other views keep their own name
Title 1view nameThe model view's name
Title 2 / 3blank
Drawing propertiesblankA saved GA drawing file, .gd
View propertiesblankA saved drawing view file, .vi. Sets the scale, filters and contents

Rows, ticks, the filter and the pin are remembered per model, in DrawingCreator.settings in the model folder.

Measured
6.5-17 sper drawing, Tekla 2025
36model views in the test model
-by hand, not measured yet
Watch out for
  • A row naming a property file that isn't in the lists fails with "not found", instead of Tekla quietly using standard. Press Refresh after saving a new file.
  • A row with no drawing name, drawing properties or view properties fails with "No drawing name", "No drawing properties" or "No view properties". A new row has both properties blank, so pick them before the first run.
  • One view per drawing. Add sections beside a plan by hand.
  • A 3D model view comes out as a plan of its view plane.
  • Nothing stops two rows, or a second run, from making drawings of the same name.
MOD-05

EK Reports

ModelNo time by hand recorded yet

Writes the EK-8xx summaries - foundations, columns and beams, wall panels, slabs, stairs, timber, steel assemblies and parts, rebar and bolts - each to its own Excel template, in one run. The columns come from the model's Organizer presets, the look from the office's Excel templates. Identical pieces share a row with their count, and a Kokku row adds up the totals.

Use it instead of exporting each report from Organizer and tidying it in Excel by hand.

You need
  • The EK-8xx_*.propertytemplate presets in the model's ProjectOrganizerData\PropertyTemplates folder, and the *_EK-8-8xx_*.xltx Excel templates in ProjectOrganizerData\ExcelTemplates
  • The model numbered. Unnumbered pieces show (?) in their position
  • EK_MARK on the steel assemblies for EK-851. Run EK Mark first
Step by step
  1. Select assemblies to report only those, or nothing for the whole model, and press Scan. EK-862 always lists every bolt of the model.
  2. Each report is listed with its prefixes, and Elements and Pos count their elements and positions. Prefixes that go into no report are listed last under Not in a report and are never exported. Untick a report or a prefix to leave it out. The tick box in the header ticks every report, and the prefixes keep their own ticks. Click a report line to fold it. Right-click a prefix and choose Move to to put it in another report, and press Save to keep that for every model.
  3. Press Enter on lines to select their elements in the model, to see what will be listed.
  4. Fill in Designer and Revision, check Date, which starts as today, and press Export. Each workbook is named after its Excel template, with the project number for 23XX, the revision for v01 and the date at the end. Open folder shows the workbooks in the model's Reports folder.
Reports beside the assembly ones
EK-852 / 853 / 854from EK-851Every part of the assemblies of EK-851's ticked prefixes, sub-assemblies included, each part once. EK-851 itself can be unticked
EK-821rebarThe rebar of the cast-in-place elements, those whose prefix starts with PV, RV, VU, LV, TM, MSN, MBP, MBT, MPL, MTR or MPV. Each prefix has a tick of its own under EK-821
EK-862boltsEvery bolt of the model, holes and studs left out, even when only a selection was scanned

Where each prefix goes is kept for the office in ek_reports.json in the macro folder, or in your own %LOCALAPPDATA%\EK Reports when that folder can't be written. The ticks, Designer and Revision are remembered per model, in EKReports.settings in the model folder.

Measured
7-9 sscan of 3,421 assemblies, Tekla 2025
0.1-15 sper report
-by hand, not measured yet
Watch out for
  • Reinstalling replaces ek_reports.json. Keep a copy of a prefix table you have saved.
  • A column added to a preset in Organizer needs its head in the Excel template too.
  • The Excel template needs a %&O%& cell where the table starts, with nothing filled in below it.
  • The Kokku row adds up area, volume and weight, never lengths.
  • Insulation is told apart by material type, so another MISCELLANEOUS part in a panel counts as insulation.
DRW-01

Opening Marks

DrawingSize dimensions and real recesses not yet checked

Finds every opening and recess in a floor plan view and crosses it out: two diagonals for an opening, one for a recess. It also finds holes no cut makes, such as a stair or shaft hole left between planks and a cast-in-place strip.

Use it on slab plans. Most of the hand time goes on finding the openings, not drawing the lines.

Step by step
  1. Open the drawing and select one view, the plan.
  2. Press Scan. The Openings tab lists what was found under five types. Click a type to expand it.
  3. Tick MARK for the crossing and DIMS for size dimensions, per opening or for a whole type. MARK starts on and DIMS off. Press Enter to outline the selected rows' openings in magenta in the drawing.
  4. Press Mark. The Results tab logs what was drawn and what was already there.
  5. To take marks off again, tick under MARK for lines and DIMS for dimensions, then press Remove. One ticked opening is enough to clear its whole type. Only the macro's own lines and dimensions are removed.
The five types
  • Inside element: bounded by one element only
  • Edge / corner: at an element's edge or corner, closed by a neighbour
  • Outer edge notch: open to the outside of the floor
  • Between elements: a gap between elements that no cut makes, like a stair hole
  • Recess: a cut that stops inside the element. One diagonal.
Settings
Min50 mmSmallest opening marked
Joint150 mmWidest gap between elements that still counts as a joint, not an opening
Recess200 mmRecesses narrower than this are ignored, such as cores opened at plank ends
Color / LineGray / solidLine style of the crossings

Scan again after changing a limit.

Measured on 1:100 plans
24 s1st floor plan, scan and mark
6 minthe same plan by hand
≤ 1 mmevery line end from the real edge
Watch out for
  • Mark never draws the same line twice, so running it again is safe.
  • Walls standing under a stair hole can split it into two openings.
  • Openings close together can get overlapping size dimensions.
  • After outlining openings, select the view again before the next Scan.
DRW-02

Auto Dimension

DrawingEvery part and the contour-plate rule not yet run in Tekla

Dimensions the assemblies in a drawing view the way a detailer would. Each element is measured to the nearest grid line. Elements in a row get one chain showing every length and gap, and openings in walls and slabs join their element's chain. Lines sit on a real face, close to the part, and step aside for existing marks, text and dimensions.

Use it on column and wall plans. It does the placing, and you still review the result. After a model change, delete the dimensions and run it again.

Step by step
  1. Open the drawing and select one view. With Grids ticked, the view must show the grid.
  2. Press Scan view. The Series tab lists every numbering prefix in the view, with counts.
  3. First tick Sub-assemblies or Rebars if you need them. They add rows such as VU- / EB_HPM24L, and changing either rebuilds the list and resets its ticks. Every series starts ticked, so untick the ones you do not want, such as rebar and embeds. Untick VU- to dimension the bolts without the concrete. Then set OPENINGS, END-ON and DIRECTION per series.
  4. Press Add dimensions. The Results tab logs what was placed and what was skipped.
  5. The window stays open, so you can dimension the next series and check the drawing in between. Each run avoids what the previous one placed.
Reading the Results tab
  • Many skipped, seen end-on: that series needs END-ON ticked (columns in a plan, for example).
  • Openings measured 0 on a wall series: check OPENINGS and Min.
Settings
OPENINGSonPer series: dimension window, door and service openings in the element's chain
END-ONoffPer series: dimension elements whose length points into the view, such as columns in a plan
DIRECTIONbothPer series: length + cross-section, length only, or cross-section only
GridsonMeasure to the nearest grid line. Untick to measure only the elements and gaps.
Sub-assembliesoffList sub-assemblies as series of their own. Unticked, only assemblies are listed.
RebarsoffList the rebars shown in the view, one row per assembly and rebar name and size, such as VU- / rebar: ankurdusvarras 20. Each bar is dimensioned to its centre line. Tick END-ON for vertical bars in a plan.
Every partoffDimension every part as its own element, not only main parts
RecessesoffAlso dimension cuts that stop inside the element. Unticked, only openings that go through are dimensioned.
Min50 mmSmallest opening dimensioned. Smaller cuts are notches or bolt holes.
Max-gap2000 mmLargest gap between aligned elements that still joins them in one chain. Wider gaps get separate dimensions. Piles and bars chain up to at least 4500 mm.
Measured on 1:100 plans
20 s1st floor plan, 70 assemblies
15 minthe same plan by hand
Watch out for
  • Chamfered or stepped ends are measured to the outer box, not the drawn edge.
  • Round piles and columns (RU / RO profiles) are measured to their centre. One exactly on a grid line gets no dimension on that axis, one a few mm off shows its offset.
  • Offsets are in model mm, so the gap on paper changes with the view scale.
  • A 5 mm joint at 1:60 is correct but too small to read.
  • A dimension that repeats one nearby is left out. Nearby means the same axis, within 3000 mm, with points within 25 mm. The Results tab counts these as repeats left out.
  • With two grid sets in the view, each element is measured to a grid line that really reaches it, so a small local grid is used only for the elements it covers.
  • Rows a grid bay apart chain only when Max-gap is larger than the gap between them, such as 6000 for 6 m bays.
  • Every part and the contour-plate length rule are new and haven't been run inside Tekla yet.
DRW-03

Drawing Check

DrawingNo installer yet

Checks the open drawing against the Esplan drawing checklist and lists what it finds in a table. It reads the title block, notes, views, dimensions, marks and pens. It never changes the drawing. So far it knows pile plans, foundation plans (pile caps, pad and strip footings) and anchor bolt plans.

Use it when a plan is ready to go to the checker. It finds the missing dimensions, marks and note topics that are slow to spot by eye, and it tells you where each one is.

You need
  • The macro file Drawing Check.cs copied into the drawings macro folder of Tekla 2025: C:\ProgramData\Trimble\Tekla Structures\2025.0\Environments\common\macros\drawings\. Copy it into the 2025 folder only, because the 2023 folder has an old first version.
  • The project status workbook (.xlsx or .xlsm) with its DokNimekiri sheet. Without it the document list rules show Not checked.
  • Model numbering up to date, and the drawing updated
Step by step
  1. Open the drawing and run Drawing Check. The status line says Open a drawing, then Check.
  2. The first time in a model, press Status file... and pick the project status workbook. The choice is saved in the model folder, so you pick it once per model.
  3. Press Check. Findings come first, Must before Should before Note. Rules that passed come last as OK.
  4. Hover a rule ID to see the rule and its checklist row. Hover a finding to see any extra detail and the abbreviations spelled out.
  5. Double-click a finding to select its objects in the drawing.
  6. Press Copy to put the findings on the clipboard as rows, ready to paste into Excel.
  7. Fix the drawing and press Check again.

Watch out for
  • Coordinate marks do not count as dimensions. A pile placed only by a coordinate mark is reported as not tied to the grid.
  • An own element drawn with a thin pen is taken as a neighbour part. It is reported only when it has a mark.
  • Overlaps with dimension texts are worked out, not read, so those findings are Uncertain. Coordinate marks are not checked for overlaps.
  • Foundation size is checked as overall length and width only, not the shape of a non-rectangular cap.
  • Anchor bolts are found by name (HPM, PPM, HIT, HAS and similar). A bolt of another make is not seen.
DRW-04

EK Coordinate Mark

DrawingNot yet checked on a live drawing

Writes a picked point's coordinates beside it, as a text with a leader line. The coordinates are measured from the base point the view is located by, in the order, unit and decimals you set. It is a plugin, not a macro, so each mark stays live and can be changed later.

Use it for setting-out points, slab corners and anchor bolts on drawings that site reads coordinates from.

Step by step
  1. Open the drawing and check the view's Location by is the base point the coordinates should be measured from.
  2. Start EKCoordinateMark from Applications & components. Set the coordinates, order, unit and decimals, then press Apply or OK. Type a name and press Save to keep them, or pick a name and press Load.
  3. Pick the coordinate point, then pick where the text goes. Both picks must be in the same view.
  4. To change marks already placed, select them, change the settings and press Modify. Get reads the settings back from a mark.
Measured from
  • Model origin: the model's global origin
  • Project base point: the project base point
  • A named base point: that base point. If the model has none of that name, it stops with an error.

Watch out for
  • A point picked outside any view creates nothing, without a message.
  • One point per mark, so many points means picking each one.
  • It hasn't been timed or checked against known coordinates on a live drawing yet.
APP-01

Tekla Setup

WindowsPartly run on Tekla 2026

Sets up a newly installed Tekla version the office way, from one window: the service pack and environments, user.ini, the title block logos, the date format, paper sizes, ribbons, the property panel and keyboard shortcuts. It is a program, not a macro, so it runs with Tekla closed.

Use it when a new Tekla version or service pack is installed, or a PC is set up. Without it, every step of the install guide is copied by hand into folders that differ per version.

You need
  • Tekla-Setup.exe, and admin rights on the PC. It asks for them as it starts.
  • Access to the server folder, \\10.168.1.3\Public\Abimaterjalid\EK-OSAKOND\02_EK-tarkvarad\Tekla Structures
  • For a brand-new version: Tekla started once and closed, so its UserSettings folder exists
Step by step
  1. Close Tekla. Double-click Tekla-Setup.exe and accept the admin prompt.
  2. Pick the Version. Every card fills its source from that version's folder on the server.
  3. Untick what isn't needed, for example the installers when the version is already installed. Select all and Clear tick or untick every card.
  4. If a file on the server has been replaced, press Browse on its card and pick the new one.
  5. Press Run selected steps. Each card shows OK or Failed. Logs opens the full log, and Copy all copies it.
  6. Start Tekla and check Ctrl+E → File locations: XS_FIRM points at the server.
